# StarDisk OS

复古操作系统风格的个人作品集网站。

## 在线访问

https://skylar-explorer.github.io/stardisk-os/

## 技术栈

- React 18 + Vite
- Tailwind CSS
- Zustand（状态管理）
- HTML5 Audio API

## 功能

- 完整桌面窗口管理系统（拖拽、最小化、层级、焦点）
- 交互式 Terminal（打字机效果、命令历史、彩蛋命令）
- 真实音乐播放器（8首歌曲、进度拖拽、音量控制）
- CD 仓库电影展示（复古 CD 播放器 + 吸入动画）
- 项目展示窗口（卡片式、可展开详情）

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
